照见 · 镜窟  Seeing Through — a mirror grotto for the kneeling bodhisattva of Mogao Cave 328

这是一个纯静态网站：把整个文件夹（index.html 和 assets / audio / film 三个子文件夹）原样上传到任何静态网页托管即可，
例如 agent.space、GitHub Pages、Netlify、Cloudflare Pages、Vercel。访问者不需要任何账号。
需要支持 WebGL 2 的浏览器（近几年的 Chrome、Edge、Safari、Firefox 都可以）。

This is a plain static site: upload the whole folder as is (index.html plus the assets, audio and film folders)
to any static host — agent.space, GitHub Pages, Netlify, Cloudflare Pages, Vercel. Visitors need no account.
Requires a browser with WebGL 2.
